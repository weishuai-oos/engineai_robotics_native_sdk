# T800 Native SDK 真机部署

适用目录：`/home/ds/robot/11.16/engineai_robotics_native_sdk`

## 1. 目标板与部署结论

T800 开发版有两块机载电脑：

| 设备 | SSH 地址 | 实测架构 | 实测内核 | 用途 |
| --- | --- | --- | --- | --- |
| Nezha（Robot PC） | `user@192.168.0.163` | `aarch64` | `6.1.141-4-engineai` | Native SDK / 运控策略 |
| NVIDIA Jetson AGX Orin 64GB（AI PC） | `ubuntu@192.168.0.162` | `aarch64` | `5.15.148-6-engine-tegra` | AI 计算 |

Native SDK 的 `src_executor` 真机流程部署到 Nezha，不部署到 Orin。两块板都是 `aarch64`，不能只用 `uname -m` 区分；`install.sh` 会检查架构，并对 T800 拒绝 Jetson/Orin 的内核或设备树特征。


## 2. 编译与下发

在开发电脑仓库根目录执行：

```bash
cd /home/ds/robot/11.16/engineai_robotics_native_sdk

./build.sh -a aarch64 -r humble -t release
./install.sh t800 robot aarch64
```

## 3. 真机启动

安装完成后，机器人重启会自动启动 Native SDK。当前开机周期需要立即启动时：

```bash
ssh user@192.168.0.163
sudo systemctl start engineai-native-sdk.service
```

查看当前启动周期的实时日志：

```bash
sudo journalctl -u engineai-native-sdk.service -b -f
```

## 4. 结束运行并恢复

```bash
sudo systemctl stop engineai-native-sdk.service
sudo systemctl disable engineai-native-sdk.service
sudo systemctl enable robotics.service
```

## 5. 真机数据采集

等终端 A 中真机程序正常启动后，另开 **终端 B**。推荐在能收到机器人
ROS2/LCM 数据的开发机完整 SDK 仓库中执行。当前 Docker 路线使用一条命令完成
容器、网络参数和话题检查：

```bash
cd /path/to/engineai_robotics_native_sdk
./tools/safety_monitor/start_real_recording.sh real_run_01 --duration 3000
```

不传运行名时会自动生成 `real_t800_<timestamp>`。采集器只订阅状态，不发布控制指令。
终端 B 按 Ctrl+C 只停止采集，终端 A 中的真机程序继续运行。数据写入终端 B 当前仓库的
`records/safety_monitor/<run_name>/`。如果 ROS2 overlay 不在默认的
`build/x86_64/ros2_env/install/setup.bash`，设置
`ENGINEAI_ROS2_OVERLAY=/path/to/setup.bash` 后再执行同一命令。

脚本默认使用 `ROS_DOMAIN_ID=69`、`ROS_LOCALHOST_ONLY=0`、
`RMW_IMPLEMENTATION=rmw_fastrtps_cpp` 和 `assets/config/t800/lcm/robot.yaml`。
如果 Docker 权限尚未在当前登录会话生效，先执行一次 `newgrp docker`。

## 6. 说明

- SDK 默认下发到 `/home/user/projects/engineai_robotics`。
- `install.sh` 会设置 `active_mode: robot`，禁用 `robotics.service`，启用 `engineai-native-sdk.service`，并提示输入机器人 sudo 密码。
- 机器人重启后自动启动 Native SDK。下载完成后不会自动启动当前服务。
- 启动后默认进入 `idle`，随后转入 `passive`。没有遥控器输入时不会进入站立、行走或起身任务。
